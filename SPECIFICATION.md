# Signet - Product Specification 

## What is Signet?
Signet is a system to synchronize bookmarks across multiple platforms:
- Android
- iOS (with a Safari extension)
- Desktop through browser extensions
  - Firefox
  - Safari
  - Chromium based browsers
- And even a website

The goal is to make that system self hostable so each client can reach a self hosted server somewhere.
What we need for a first implementation are: 
- Signup (email and password)
- Bookmark management:
  - Add a bookmark (title, url, image; default will just use the page OG image)
  - Edit a bookmark
  - Delete a bookmark
- Bookmark folder management
  - Simple folder
  - Nested folder
- Share a bookmark / a foldre - with accounts from the same server
- Import / export features
  - Backup
