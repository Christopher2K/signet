# Signet

Signet is a self-hostable, multi-user bookmark sync system with web and native clients.

## Self-hosting

- [Docker quickstart](docs/self-hosting-quickstart.md) — install a local instance from published images or source.
- [Operator guide](docs/self-hosting.md) — public HTTPS, upgrades, backups, restores, password resets, maintenance, and safe removal.

The published deployment uses the `signet-api` and `signet-web` images from GHCR. No Node.js, pnpm, Elixir, or PostgreSQL installation is required on the Docker host.
